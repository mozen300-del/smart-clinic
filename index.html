نظام العيادة الذكية (Smart Clinic) جاهز

مشروع تطبيق عملي لمقرر هندسة البرمجيات - درجة ماجستير تقانة المعلومات (الدفعة 18).

📌 نبذة عن المشروع:

يستهدف النظام تسهيل عملية حجز المواعيد بين المرضى والأطباء، إدارة الملفات الطبية، وتنظيم حركات العيادة بكفاءة عالية وفق منهجية تطوير البرمجيات الرشيقة (Agile).

📊 المخططات الهندسية (UML Diagrams):

  • Use Case Diagram: تحليل تفاعلات المستخدمين (Patient, Doctor, Admin) مع النظام.
  • Class Diagram: توضيح الكلاسات الأساسية (User, Patient, Doctor, Appointment, Medical Report).
  • Activity Diagram: مسار سير العمل لخطوات حجز الموعد والتحقق من التوفر.

⚙️ الأكواد والأدوات المستخدمة:

  • لغة البرمجة: Python (OOP).
  • إدارة المشروع والمهام: Git & GitHub.
  • معايير الجودة: تطبيق أخلاقيات هندسة البرمجيات وحماية بيانات المرضى.
